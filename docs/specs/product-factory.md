# Product Factory — цифрові продукти для Etsy

**Статус:** задум (2026-11-11), чекає перевірки правил Etsy та підтвердження власника. Не затверджена специфікація.
**Пов'язані:** [specs/pebble.md](pebble.md) (пошук ніш), [specs/promotion-strategy.md](promotion-strategy.md) (план просування,
дослідження ніш), [ADR-0019](../decisions/0019-connection-access-levels.md) (рівні доступу Etsy),
[ADR-0023](../decisions/0023-tiktok-integration.md), [ADR-0024](../decisions/0024-promotion-strategy-module.md).

## 1. Ідея (третій проєкт власника)

«Фабрика продуктів» для Etsy: знайти нішу в тренді → за допомогою AI створити **цифровий продукт** (принтабли, шаблони,
планери, SVG, клипарт тощо) → виставити на Etsy → просувати в Pinterest, TikTok, YouTube (де є сенс) → виміряти
продажі й повернути висновки в пошук ніш. Це третій проєкт у workspace поряд з Gushka й модом для ETS2/ATS.

## 2. Цикл і модулі Adelie

| Крок | Що робить | Модуль / стан |
|---|---|---|
| 1. Ніша в тренді | Open Discovery: сигнали зростання, групування, попит і конкуренція, оцінка можливості | Pebble + спільне ядро «Дослідження ніш» ([promotion-strategy §4.2](promotion-strategy.md)); частково є PoC 0 |
| 2. Продукт | AI-генерація файлів і зображень; перевірка людиною | **нове**; джерело генерації не вибране |
| 3. Оголошення на Etsy | чернетка: назва, теги, опис, фото, цифровий файл | Etsy підключено з повним доступом (редагування є); **створення оголошень і завантаження цифрових файлів — нове** |
| 4. Просування | календар, тексти, теги/хештеги, посилання з UTM | план просування (специфікація); публікація в Pinterest/TikTok/YouTube — **нове**, вимагає доступів і аудитів |
| 5. Вимірювання | продажі, перегляди, «улюблене» по оголошенню; метрики пінів/відео | Etsy, Pinterest, Instagram є; TikTok/YouTube — за ADR-0023 і окремим ADR |
| 6. Навчання | що продається → які ніші й формати брати далі | зв'язок Etsy-продажів із нішами/гіпотезами — **нове** |

## 3. Спільне ядро «Дослідження ніш»

Одне ядро для трьох споживачів: **провайдери даних** (Pinterest Trends, Etsy API, DataForSEO/Serper/SerpApi, YouTube),
**ніші й кошики слів**, **докази й кеш**, **оцінка можливості**. Застосування: поради й план просування (ніша відома),
Pebble/Open Discovery (ніші нові), Product Factory (вибір ніші для нового продукту). Порядок: спершу ядро й режим «ніша
відома» для Gushka (теги, поради), потім Open Discovery на тому ж ядрі.

## 4. Принципи й межі

- **Людина підтверджує кожен продукт і кожне оголошення.** Adelie знаходить, готує чернетки, пропонує; публікує лише за
  явною дією користувача (як у ADR-0019: створення оголошення — через чернетку й окреме підтвердження; Etsy бере $0.20 за
  оголошення).
- **Невеликі партії й експерименти:** кілька продуктів у нішу, вимір, потім масштаб; кожен експеримент має гіпотезу й метрику.
- **Якість і унікальність:** AI — інструмент для власного дизайну автора, а не конвеєр однакових шаблонів.
- Жодної масової автоматизації без перевірки людиною.

## 5. Ризики (перевірити до розробки)

1. **Політика Etsy щодо AI** (Creativity Standards). За сторонніми джерелами: AI-допомога в цифрових товарах дозволена, але
   її треба розкрити (позначка «Designed by») і не видавати за ручну роботу; заборонені продаж «промптів» як товару, продукти
   з куплених/чужих шаблонів, виготовлення не за власним оригінальним дизайном; цифрові завантаження потребують зображень-
   превʼю. Джерела розходяться в датах і подробицях; **офіційні сторінки Etsy (`etsy.com/legal/creativity`, API Terms of Use)
   ще не прочитані** — зробити до будь-якої розробки. Порушення може закінчитись блокуванням магазину.
2. **Насичення й якість.** Тренд, видимий у Pinterest Trends чи за обсягами, бачать тисячі продавців; конкуренція цифрових
   принтабл висока, Etsy її обмежує. Очікувати мало продажів без реальної якості.
3. **Авторське право.** Згенеровані AI зображення в США без людської творчості не мають авторського захисту (можуть
   копіювати); уникати чужих персонажів і торгових марок — тренди часто саме про них.
4. **Мітки AI на платформах** (Pinterest, TikTok, YouTube) і зміни їхніх правил.
5. **API:** створення оголошення = чернетка з типом `download` + окреме завантаження файлу; у документації Etsy є
   суперечності в послідовності — перевірити в тестовому режимі. Ліміти й умови автоматизації з офіційного тексту не
   підтверджені.
6. **Публікація в соцмережі** вимагає доступів (Pinterest Standard access, аудити TikTok/YouTube для публічних постів).

## 6. Порядок (пропозиція)

1. **Прочитати офіційні правила Etsy** (Creativity Standards, API Terms) і зафіксувати висновки тут.
2. **Перевірка вручну:** одна ніша, 3–5 продуктів майже вручну (інструменти генерації — на вибір власника), реальні продажі.
3. Ядро «Дослідження ніш» + поради з тегами для Gushka (дають дані й корисні для цього проєкту).
4. Створення оголошень і цифрових файлів через API (чернетки, підтвердження людиною).
5. Публікація в Pinterest/TikTok/YouTube після відповідних доступів.
6. Зворотний зв'язок «що продається → нові ніші».

## 7. Відкриті питання

- Які саме цифрові продукти (принтабли, планери, шаблони, SVG, клипарт…)? Чи є вже ідеї ніш?
- Чим генерувати продукти (інструменти, ліцензії, вартість) і чи є вимоги до якості/стилю?
- Окремий магазин Etsy для цього проєкту чи той самий (GushkaWoolRugs)? Окремий зменшує ризик для основного бізнесу, але
  потребує окремого підключення (Personal Access — до 5 магазинів разом із власним).
- Оформлення (ФОП, податки, продаж цифрових товарів за кордон) — поза Adelie, але впливає на запуск.
