# Статус проєкту

_Оновлено: 2026-11-13_

## Поточний етап

**Adelie — власний інструмент власника** ([ADR-0025](decisions/0025-own-tool-first.md), запропоновано): будується під три
проєкти-експерименти з сигналами успіху й щомісячним переглядом — **Gushka** (вовняні вироби: Etsy, два сайти,
Pinterest, Instagram), **мод для ETS2/ATS** (безкоштовний, канали з нуля) і **Product Factory** (цифрові продукти для
Etsy, задум). Команда, біллінг і зовнішні клієнти — відкладено. Етапи MVP-1 1–2 закрито; план:
[plans/mvp-1.md](plans/mvp-1.md).

Усе працює на **dev.adelie.space** (production відкладено — див. «Відкриті питання»).

## Що вже є

**Основа.** Репозиторій `kashkadv/adelie.io`, правила — [rules.md](rules.md); вимоги —
[product-requirements.md](product-requirements.md). Монорепо: api (NestJS + Better Auth), web (Next.js), worker (BullMQ),
db (Prisma), shared, platforms, tracker; CI. Домен `adelie.space` (Cloudflare; пошта `hello@`/`privacy@` → Gmail),
Tailscale. Dev-сервер — VM `adelie` на Proxmox (Docker, PostgreSQL 18, Redis 8): [infra/server-setup.md](infra/server-setup.md);
деплой вручну `pnpm deploy:dev`. Сайт https://adelie.space (лендінг, privacy policy, terms; en/uk). Бренд і шрифти —
[ADR-0009](decisions/0009-design-system.md) (Inter, Onest, Playwrite IT Trad 300; self-hosted).

**Застосунок.** Два шари (шапка й сайдбар на фоні, контент у скляній панелі), світла/темна тема, en/uk
([ADR-0006](decisions/0006-i18n.md)), власні елементи керування й підказки «i». Сайдбар: **Головна** (`/`, поки
заготовка під віджети) · **Статистика** (`/statistics`) · **Просування** (Контент) · **Продажі** (Товари, Замовлення) ·
Звіти · Підключення · Налаштування ([ADR-0018](decisions/0018-promotion-and-sales.md)). Картки піна, товару й
замовлення займають місце панелі поверх розмитого фону; форми — вікна по центру. Профіль `/me`
([ADR-0010](decisions/0010-personal-profile.md)), проєкти й налаштування проєкту ([ADR-0014](decisions/0014-project-management.md)),
налаштування інтерфейсу користувача, напр. колонки таблиць ([ADR-0016](decisions/0016-user-preferences.md)).

**Підключення** (`/connections`; адаптер — [ADR-0011](decisions/0011-platform-adapters.md)):
- Платформи: **Pinterest**, **Instagram** ([ADR-0015](decisions/0015-instagram-integration.md)), **TikTok** (етап 1, sandbox —
  [ADR-0023](decisions/0023-tiktok-integration.md)), **Etsy** (точка продажу), **сайти** через фід Google Merchant
  ([ADR-0021](decisions/0021-website-catalog-feeds.md)). Подробиці — `docs/integrations/*.md`.
- Вхід через OAuth (Etsy — з PKCE), токени шифруються (AES-256-GCM); запрошення-посилання без входу в Adelie
  ([ADR-0012](decisions/0012-connect-invitations.md)); від'єднати / видалити з даними / приховати; «Синхронізувати
  зараз»; порядок перетягуванням і власні назви підключень.
- Рівні доступу «Лише читання / Повний доступ» (Etsy — [ADR-0019](decisions/0019-connection-access-levels.md)); реєстр
  функцій і дозволів з «Оновити доступ» (перейти або скопіювати посилання; перевірка, що згоду дав саме той акаунт) —
  [ADR-0020](decisions/0020-connection-features-update-access.md).
- Синхронізація у worker: первинна (до 90 днів історії) і щоденна після 04:00 UTC; сирі відповіді 90 днів (без
  персональних даних покупців).

**Статистика.** По одній платформі: показники з порівнянням із попереднім періодом, графік, розбивка; для магазину —
замовлення, дохід, середній чек, країни. **Аудиторія Pinterest** (вік, стать, країни, міста, пристрої, інтереси з
індексом спорідненості) — дозвіл `ads:read`.

**Просування → Контент.** Одна платформа за раз; метрики за період зі щоденних значень (Pinterest — з API,
[ADR-0013](decisions/0013-post-daily-metrics.md); Instagram — з різниці знімків від 2026-11-07,
[ADR-0017](decisions/0017-instagram-post-daily.md)); колонки на вибір, фільтри окремо для кожної платформи, CSV; картка
публікації з усіма метриками й динамікою. Посилання дописів (`social_post_link`: власне + з опису/підпису) зіставляються
з товарами; фільтр «Веде на».

**Продажі.**
- **Товари:** перемикач каналів (Etsy | gushka.ua | gushka.world), у кожного свої колонки й фільтри; той самий артикул на
  інших каналах; «Проблеми товарів» (критичні / важливі / звернути увагу, «Ігнорувати»); SKU й двійники лістингів;
  картка товару (продажі по місяцях, замовлення, піни, «На сайті / В Etsy», SEO-перевірка сторінки сайту).
- **Редагування товарів Etsy** (повний доступ): назва, опис (кнопка «Список»), теги, ціна/кількість/SKU — «одна для
  всіх / за опцією / кожна варіація»; живе читання з Etsy, «було → стане», захист від перезапису (409), історія змін.
- **Замовлення:** список на всю ширину з фільтрами (статус, оплата, відправлення, країна, пошук) і сортуванням;
  «Що лишається магазину» (продажі з оплачених замовлень, комісії й Etsy Ads із журналу платежів); картка замовлення з
  посиланням у кабінет Etsy. Скасовані й повністю повернуті не рахуються продажами.

**Flipper — трекер сайтів** ([ADR-0022](decisions/0022-flipper-tracker.md)): `flipper.js` (≈ 7 КБ, `packages/tracker`),
приймач `POST /collect`; анонімний режим до згоди або повний; канали за GA4; автовиявлення подій з `dataLayer` (зокрема
кроки оформлення Gushka); серверний `Purchase` (`POST /collect/server`, ключ сайту, дедуплікація за `transaction_id`);
кабінет: аналітика, джерела, оформлення, події наживо, налаштування й встановлення. Установлено на **gushka.ua**. **Що вимірюємо — налаштування сайту** ([ADR-0026](decisions/0026-flipper-site-goals.md)): тип
(магазин / лендінг; реєстр, розширюється), цілі (подія, сторінка за шаблоном, перехід на інший сайт), своя воронка;
рахується з сирих подій, тож зміни діють і на минуле. Кабінет магазину Gushka після переходу показує ті самі цифри (звірено).

**Просування → Посилання (Link Builder)** ([ADR-0027](decisions/0027-link-builder.md)): мічені посилання (канал з
реєстру, кампанія з підказками, місце) у двох формах — повна з UTM і коротка `go.adelie.space/<код>` (Cloudflare Worker +
KV, клік у фоні в `POST /go/clicks`); по кожному — кліки, візити й цілі Flipper за період; зміна адреси, архів. Коротка
форма запрацює після налаштування Cloudflare ([plans/link-builder.md](plans/link-builder.md)).

**Дані Gushka на dev:** Pinterest `gushkawool` (~55 пінів; 26 ведуть на gushka.ua, 2 — на Etsy), Instagram
`gushka.wool` (~780 публікацій, 87 тис. підписників), Etsy `GushkaWoolRugs` (повний доступ; 109 активних товарів,
165 замовлень з 2020 р.; журнал платежів з 2020 р.), сайти `gushka.ua` (грн) і `gushka.world` (USD) — фіди по ~205
позицій. Тестові: Instagram `adelie.if`; TikTok `nilsolav` у проєкті «ETS 2 | Tacho mod».

## Наступні кроки

1. **Link Builder:** токен Cloudflare → `pnpm deploy:go` → перевірити коротке посилання й клік (кроки —
   [plans/link-builder.md](plans/link-builder.md)). Далі: вибір товару з каталогу як адреси, зв'язок посилання з дописом.
2. **Резервні копії бази dev** ([infra/backups.md](infra/backups.md)): скрипт з перевіркою відновлення і зашифрована копія
   в Cloudflare R2 працюють (2026-11-12). Щонічний таймер на VM встановлено. Розшифрування ключем власника перевірено. Третя копія —
   на Mac власника: `pnpm backup:pull` (час від часу).
3. **TikTok:** публічне відео в тестовому акаунті → перевірити таблицю й картку; демо-відео й заявка на App Review; потім
   бойові ключі. Публікація (Content Posting API) — окремою ревізією; до аудиту пости лише приватні.
4. **Flipper:** серверний `Purchase` з бекенду Gushka **працює** (підтверджено 2026-11-12: 4 покупки з gushka.ua, 3 з
   них прив'язані до візиту й успадкували канал — Google, Facebook, прямий; одна без відвідувача — «Без джерела»). Далі: увімкнути
   gushka.world; потім — правила з кабінету (шаблони адрес, CSS-селектори), JSON-LD `Product`, режим-проксі,
   production-хости `cdn.`/`events.`, оновлення privacy policy.
5. **Від власника:** Gushka — тип акаунта TikTok, канал YouTube, Threads, GA4, Merchant Center; мод — де розповсюджувати;
   **реклама Instagram** — кроки в Meta (Marketing API, `ads_read` у конфігурації, перепідключення).
6. **Розробка далі:** порівняння цін між каналами; продажі сайту через Flipper; запис ціни й кількості «за опцією» в
   Etsy (SKU за кольором уже працює); «Реклама» (Etsy Ads, Instagram, Pinterest); модуль стратегії просування
   (ADR-0024); дослідження ніш (Pebble / Product Factory).

## Відкриті питання

- **Production відкладено** (2026-11-07) до перших зовнішніх користувачів; доти dev = «production для Gushka»
  (міграції обережно, тестові дані — лише на окремому користувачі). Хостинг — кандидат домашній Proxmox. Оточення
  `staging` і `app` — після рішення про хостинг; деплой у `dev` згодом автоматично з `main`. Деталі —
  [plans/infra-discussion.md](plans/infra-discussion.md).
- **Сповіщення** (пошта тощо, напр. «потрібне перепідключення») — пізніше; поки лише в застосунку. Місце — «Профіль».
- **Юридичне:** privacy policy й Terms of Service — чорновики (оператор «Adelie», право України, безкоштовна бета).
  Є **ФОП** — для умов, Business Verification у Meta (Instagram Advanced access) і комерційного доступу Etsy. Зміни
  privacy policy щодо Etsy — у репозиторії, на сайт після перегляду власником.
- **Etsy API:** personal app «adelie» (Personal Access, 5 QPS / 5K на добу, до 5 магазинів). **Commercial Access** —
  із першим зовнішнім продавцем (ADR-0025): будь-яка кількість магазинів, можливо вищі ліміти; платний продукт на Etsy
  API — лише з дозволу Etsy.
- **Редагування пінів з Adelie** (2026-11-09, поки ні): `PATCH /v5/pins/{id}` потребує `pins:write`; не з'ясовано, чи
  Trial-доступ дозволяє змінювати наявні піни (створені через API на Trial — sandbox). Перевірити на тестовому піні
  акаунта Adelie, за потреби — заявка на Standard access; окремий ADR перед реалізацією.
- **Публікація** в TikTok/YouTube/Pinterest через API обмежена аудитами навіть для власного використання (ADR-0025).
- **Pebble** — тренди й комерційні можливості: [specs/pebble.md](specs/pebble.md). PoC 0: ✅ Pinterest Trends (топ-слова,
  52 тижні, 18 регіонів без UA), ✅ Etsy API (публічні оголошення, статистика магазинів). Спільне ядро «Дослідження ніш»
  з Product Factory і стратегією просування.
- **Product Factory** — перед розробкою прочитати правила Etsy щодо AI (Creativity Standards) і API Terms.
- **«Головна» як простір з віджетами** (кожен налаштовує під себе) — коли буде з чого збирати віджети.
- 2FA на Pinterest-акаунті Adelie: SMS на +380 не пройшла — через застосунок-автентифікатор.

## Підказки для локального запуску

- Новий ПК: Tailscale → `git clone` → кроки з README (`pnpm env:pull && pnpm build && pnpm dev`).
- `pnpm` є лише в Node 24: у новій вкладці `nvm use` (або раз `nvm alias default 24`).
- Якщо після перенесення сторінок `pnpm dev` віддає стару розмітку — `rm -rf apps/web/.next` і перезапуск.
- Після додавання нового пакета (`packages/*`) — перезапустити `pnpm dev`: `nest --watch` не підхоплює пакет, якого не
  було на старті.
- Повну перевірку як у CI робити в чистому клоні (rules.md §4), а не `build` у робочій копії поруч із `pnpm dev`.
