# ADR-0041: GPU-воркер на ПК за потреби (pull-модель)

- **Статус:** запропоновано
- **Дата:** 2026-11-24
- **Пов'язані:** [ADR-0040](0040-publication-workshop.md), [ADR-0024](0024-promotion-strategy-module.md),
  [infra/local-llm.md](../infra/local-llm.md)

## Контекст

Майстерні ([ADR-0040](0040-publication-workshop.md)) потрібна обробка зображень (апскейл, вирізання з фону, зміна фону,
прибирання виробу зі сцени). Є робочий ПК власника: i5-12600K, RTX 3060 Ti (**8 ГБ VRAM**), 32 ГБ RAM, в одній локалці з
сервером (VM `adelie` на Proxmox). ПК використовується для роботи, тож доступний не завжди; Ollama й ComfyUI не мають
автентифікації й не мають дивитись в інтернет.

## Рішення

1. **Pull-модель:** на ПК працює **агент**, який сам звертається до API Adelie (приватна мережа Tailscale або HTTPS);
   Adelie ніколи не підключається до ПК. Порти ComfyUI/Ollama не відкриваються назовні.
2. **Heartbeat кожні ~30 с:** стан ПК (вільна VRAM і завантаження GPU з `nvidia-smi`, перемикач власника, за потреби —
   простій користувача). **Доступний** = свіжий heartbeat (< 90 с) **і** перемикач «Дозволити Adelie GPU» увімкнений **і**
   вільно ≥ ~6 ГБ VRAM. Інакше «зайнятий» (гра, рендер) або «офлайн».
3. **Черга:** завдання (`gpu_job`) стають у чергу зі статусом «чекає на ПК»; доступний агент забирає завдання (claim),
   виконує воркфлоу ComfyUI локально й вантажить результат. Для зображень хмарної альтернативи немає — завдання чекають.
   Текст має запасний шлях через OpenAI (ADR-0024).
4. **Індикатор** 🟢 готовий · 🟡 зайнятий · ⚪ офлайн у шапці/майстерні; необов'язково Wake-on-LAN («Розбудити ПК»).
5. **Моделі під 8 ГБ:** апскейл (Real-ESRGAN / 4x-UltraSharp), вирізання (BiRefNet / rembg), фон і inpaint (SDXL),
   прибирання об'єкта (LaMa), редагування за інструкцією (FLUX.1 Kontext у GGUF Q4 — на межі, 1–3 хв). Qwen-Image-Edit
   (20B) не підходить. Одночасно на GPU — один тип завдань (зображення чи текстова модель).
6. **Воркфлоу ComfyUI** лежать у репозиторії (`infra/gpu-agent/workflows/`), агент — там же.

## Альтернативи

- **Adelie опитує ComfyUI на ПК напряму** — потрібні відкриті порти без автентифікації, ПК «зайнятий» не розрізнити.
- **Хмарна генерація зображень** — платно й не потрібно для апскейлу й вирізання; може стати запасним шляхом пізніше.
- **Постійний сервер з GPU** — відкладено (шум, електроенергія, ціна); перегляд, якщо обсяг виросте.

## Наслідки

- Таблиці `gpu_worker`, `gpu_job`; ендпоінти heartbeat і claim з автентифікацією агента (ключ воркера).
- Пропускна здатність: ~1 хв на картинку тяжкими моделями → 20 картинок ≈ 20 хв; агент працює у фоні.
- Власнику: встановити ComfyUI на ПК, перевірити якість на 3–5 реальних фото Gushka (крок 1 плану).
