# ADR-0004: Порядок підключення платформ

- **Статус:** прийнято
- **Дата:** 2026-11-05

## Контекст

Перший користувач — Gushka (присутній на Instagram, Pinterest, Etsy).
Доступні акаунти: Pinterest — продовий акаунт Gushka; Instagram — робочий акаунт,
лише read-доступ; TikTok — тільки тестовий. Обговорення:
[plans/mvp-discussion.md](../plans/mvp-discussion.md).

## Рішення

1. **Pinterest** — перша платформа (MVP-1).
2. **Instagram** — друга, лише read-only scopes.
3. **TikTok** — пізніше.
4. **Etsy** — поза MVP, кандидат для напряму E-commerce Intelligence (ТЗ 14.4).

## Альтернативи

- Instagram першим — найбагатші insights, але ризиковано обкатувати пайплайн
  на робочому акаунті.
- TikTok першим — у Gushka немає акаунта, лише тестові дані.

## Наслідки

- Етап 0 (перевірка API) починаємо з Pinterest.
- Adapter-архітектура обкатується на Pinterest, тому треба стежити, щоб
  контракт не «прилип» до специфіки Pinterest.
