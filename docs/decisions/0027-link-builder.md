# ADR-0027: Link Builder — мічені й короткі посилання

- **Статус:** прийнято
- **Дата:** 2026-11-12
- **Пов'язані:** [ADR-0022](0022-flipper-tracker.md), [ADR-0026](0026-flipper-site-goals.md),
  [ADR-0024](0024-promotion-strategy-module.md), [specs/tracker.md](../specs/tracker.md) (A.4)

## Контекст

Flipper визначає канал за referrer: видно платформу, але не допис, а застосунки (Instagram) referrer часто не передають —
візит стає «прямим». На Etsy скрипта немає, тож переходи туди з біо чи пінів не видно взагалі. Стратегії просування
(ADR-0024) потрібне чесне вимірювання: «це посилання в цьому місці дало стільки візитів і цілей».

## Рішення

1. **Посилання — сутність проєкту** (`tracked_link`): куди веде, канал (`utm_source` + `utm_medium` з реєстру каналів),
   кампанія, місце (`utm_content`), назва. Мітки нормалізуються (нижній регістр, пробіли → `-`), тож один канал не
   розпадається на `Instagram` / `insta`.
2. **Кожне посилання має дві форми** — користувач копіює потрібну:
   - **повна** — адреса з UTM-мітками; працює без жодного нашого сервера;
   - **коротка** — `https://go.adelie.space/<код>` (7 символів `a-z0-9`): рахує клік і перенаправляє на повну.
     Потрібна там, де Flipper нічого не бачить (Etsy, Nexus, Workshop), де посилання довге (біо) і де адресу треба
     змінити вже після публікації.
3. **Короткі посилання обслуговує Cloudflare Worker** на `go.adelie.space` з таблицею «код → адреса» у Workers KV, а не
   домашній сервер: перенаправлення працює, навіть коли VM недоступна. API записує в KV при створенні й зміні. Клік
   Worker передає в API (`POST /go/clicks`, спільний секрет) у фоні; якщо API недоступний — клік губиться, перехід
   — ні. Тимчасове перенаправлення (302), щоб зміна адреси діяла одразу.
4. **Клік без персональних даних:** час, хост referrer, країна (від Cloudflare), тип пристрою, ознака бота (попередній
   перегляд посилання в месенджерах і соцмережах — бот). IP не зберігається.
5. **Результат посилання:** кліки (коротка форма) + для адрес на сайтах проєкту з Flipper — візити, відвідувачі й цілі
   (ADR-0026) подій з тими самими мітками. Тому набір міток (`source`, `medium`, `campaign`, `content`) унікальний серед
   активних посилань проєкту; без указаного місця `utm_content` = код посилання.
6. **Після створення мітки не змінюються** (вони вже в опублікованих повних адресах); змінюються назва й адреса
   призначення. Архівування ховає посилання зі списку, але коротка форма й далі веде на адресу.
7. **Кампанії поки — текст** з підказками з уже вживаних у проєкті; окремий список — разом з календарем/стратегією.
8. Вартість: безкоштовний тариф Workers (100 тис. запитів і 100 тис. читань KV на добу, 1 тис. записів KV) з запасом.

## Альтернативи

- **Лише повні UTM-посилання** — не видно Etsy й зовнішніх сайтів, адресу не змінити після публікації.
- **Перенаправлення через API на домашньому сервері** — падіння VM ламає посилання в усіх публікаціях.
- **Сторонній скорочувач (Bitly тощо)** — платно, чужий домен, дані про кліки не в Adelie.
- **Кліки в Analytics Engine / Queues Cloudflare** — надійніше за фонову передачу, але платні й складніші; повернемось,
  якщо втрати кліків будуть помітні.

## Наслідки

- `go.adelie.space` поки одне на dev (dev = «production для Gushka»); з production-оточенням Worker передаватиме кліки
  туди.
- Потрібен токен Cloudflare API (Workers Scripts, Workers KV, Workers Routes, DNS для `adelie.space`) — у
  `~/adelie/env/dev.env` на сервері; Worker розгортається звідти (`pnpm deploy:go`).
- Без налаштувань Cloudflare Link Builder працює з повними посиланнями, коротка форма недоступна.
- Далі: вибір товару з каталогу як адреси, зв'язок посилання з дописом (`social_post`), календар і стратегія.
