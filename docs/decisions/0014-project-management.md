# ADR-0014: Керування проєктами й налаштування проєкту

- **Статус:** прийнято
- **Дата:** 2026-11-07

## Контекст

ADR-0007 описує workspace з кількома проєктами, але досі проєкт створювався лише один — під час реєстрації, і
змінити його не було де. Сторінка «Налаштування» була заготовкою. Потрібно додавати проєкти й мати сторінку
базових налаштувань проєкту, яку можна розширювати.

## Рішення

- **Створення:** пункт «+ Новий проєкт» у перемикачі проєктів (шапка). Питаємо лише назву; часовий пояс —
  з браузера, валюта й мова звітів — з поточного проєкту. Після створення проєкт стає поточним, відкриваються
  «Акаунти» (наступний крок — підключити акаунт).
- **Налаштування** — сторінка «Налаштування» (`/settings`) — налаштування **поточного проєкту**, секціями:
  «Загальне» (назва), «Регіональні» (часовий пояс, валюта, мова звітів), «Видалення проєкту». Нові
  налаштування додаються новими секціями. Посилання — також у перемикачі проєктів.
- **Права:** створювати й видаляти проєкти — Owner, Admin (вони й так бачать усі проєкти); змінювати
  налаштування — Owner, Admin, Manager (у доступних їм проєктах); Analyst і Viewer бачать налаштування лише
  для читання.
- **Видалення:** незворотне, каскадно разом з акаунтами й усіма даними; підтвердження введенням назви
  проєкту; останній проєкт workspace видалити не можна.
- **API:** `POST /workspaces/:id/projects`, `PATCH|DELETE /workspaces/:id/projects/:projectId`. Перевірки:
  назва 1–80 символів, часовий пояс IANA, валюта ISO 4217 (`Intl.supportedValuesOf`), мова звітів — `en`/`uk`.

## Альтернативи

- **Окремий розділ налаштувань workspace з переліком проєктів** — знадобиться разом зі сторінкою команди
  (учасники, ролі, призначення на проєкти); поки достатньо перемикача.
- **Форма створення з усіма полями** — зайве тертя; розумні значення за замовчуванням, змінити можна потім.
- **М'яке видалення (архів)** — можна додати пізніше; поки достатньо «Приховати» для акаунтів і явного
  підтвердження для видалення.

## Наслідки

- Часовий пояс і валюта проєкту поки лише зберігаються: межі днів у метриках — UTC, продажів ще немає. Їх
  використання — разом зі звітами й трекером.
- Призначення Manager/Analyst/Viewer на проєкти (ADR-0007) — разом зі сторінкою команди.
