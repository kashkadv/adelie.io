# ADR-0017: Щоденні метрики публікацій Instagram із різниці знімків

- **Статус:** прийнято
- **Дата:** 2026-11-07

## Контекст

Meta віддає статистику публікацій Instagram лише підсумком за весь час (`/{media-id}/insights`, period
`lifetime`), без розбивки по днях. Користувачу потрібні метрики публікацій за період («перегляди за останні 7 днів»),
як для пінів Pinterest (ADR-0013).

## Рішення

- Щоденні значення публікації = **різниця lifetime-підсумків** між синхронізаціями. Додаткових запитів немає:
  підсумки приходять разом зі списком публікацій (вкладений `insights`, 50 публікацій на запит).
- Рахується в момент запису знімка (`PostMetricValue` пишеться лише при зміні): нове значення − попереднє →
  `PostMetricDaily` (та сама таблиця, що й у ADR-0013). Кілька синхронізацій за день додаються.
- **День:** щоденна синхронізація (після 04:00 UTC) записує зміну у **вчорашній** день; але не раніше, ніж
  уже покритий день публікації чи день її попереднього знімка (повторна синхронізація того ж дня продовжує цей день).
- **Покриття** `dailyFrom..dailyTo` (ADR-0013) росте для всіх публікацій із базовим знімком, навіть без змін:
  усередині покриття відсутній рядок = 0.
- Публікація, вперше побачена, — лише базова точка; виняток — опублікована після попередньої успішної
  синхронізації: усі її значення — нова активність.
- Від'ємні різниці (Meta перераховує) зберігаються як є — суми за період узгоджені з підсумком.
- Адаптер позначає це `capabilities.postDailyFromSnapshots`; Pinterest і далі бере дні з API (ADR-0013).
- «Контент» для Instagram отримує вибір періоду; метрики за період — перегляди, охоплення, лайки, коментарі,
  збереження, поширення. Картка публікації — графік по днях.

## Альтернативи

- Лише підсумок за весь час — не відповідає на питання «що відбувалося цього тижня».
- Окремий запит insights на кожну публікацію щодня — та сама інформація (lifetime), але в 50 разів більше запитів.

## Наслідки

- **Історії назад немає:** дні накопичуються з першої синхронізації після впровадження (2026-11-07);
  інтерфейс каже «дані з …».
- Межа дня — момент синхронізації, а не опівніч; пропущена синхронізація кладе два дні в один.
- Охоплення (унікальні акаунти) за період — приріст охоплення, тобто нові акаунти; підказка це пояснює.
- Знімки ростуть лише при змінах; за потреби старі знімки можна проріджувати — дні вже в `PostMetricDaily`.
