# План: Майстерня публікацій

**Статус:** план (2026-11-24), код не почато. Рішення: [ADR-0040](../decisions/0040-publication-workshop.md),
[ADR-0041](../decisions/0041-gpu-worker-on-demand.md). Пов'язані: [content-calendar.md](content-calendar.md),
[link-builder.md](link-builder.md), [infra/local-llm.md](../infra/local-llm.md).

## Етап 0 — перевірка якості на ПК (власник, години)

- [ ] Встановити ComfyUI на ПК; вручну пройти конвеєр на 3–5 фото Gushka: вирізання (BiRefNet), новий фон (SDXL inpaint),
  апскейл (Real-ESRGAN), прибирання виробу (LaMa).
- [ ] Спробувати FLUX.1 Kontext (GGUF Q4) на 8 ГБ: час і якість.
- [ ] Рішення: які воркфлоу беремо; зафіксувати в `infra/gpu-agent/workflows/`.

## Етап 1 — майстерня без GPU

- [ ] Figma: токен у налаштуваннях проєкту (зашифрований); «Синхронізувати з Figma»; таблиця шаблонів (канал, розмір,
  слоти `#photo/#title/#logo/#badge`).
- [ ] Рендерер Satori + resvg на сервері; self-hosted шрифти; PNG 1000×1500 і 1080×1350.
- [ ] Модель: візуали й текст каналу в записі календаря (міграція), зберігання зображень.
- [ ] Інтерфейс «Створити» в картці запису: старт з ідеї/товару (фото з каталогу) / порожньо; вибір шаблону й кадрування.
- [ ] AI-текст каналу: Pinterest (назва, опис, теги, alt), Instagram (підпис, хештеги); ліміти; редагування.
- [ ] Мічене `go.`-посилання з Link Builder в тексті.
- [ ] Видача: PNG, копіювання текстів, «Відкрити створення піна», дата в календар.
- [ ] «Копія на інший канал».
- [ ] Пакетні дії: підготовка збірок для запланованих записів тижня, серія за шаблоном, перегляд сіткою.

## Етап 2 — GPU-воркер

- [ ] `gpu_worker`, `gpu_job`, ендпоінти heartbeat і claim; ключ воркера.
- [ ] Агент на ПК (`infra/gpu-agent`): heartbeat, перемикач «Дозволити Adelie GPU», перевірка VRAM, запуск воркфлоу ComfyUI.
- [ ] Індикатор стану ПК; черга «чекає на ПК»; Wake-on-LAN (за потреби).
- [ ] Дії в майстерні: апскейл, вирізання, новий фон, прибрати виріб; варіанти й вибір кращого.

## Етап 3 — рубрика «З Гушкою / без Гушки»

- [ ] Пара кадрів (з виробом / без), шаблони рубрики, швидке створення двох записів.

## Відкриті питання

- Сховище зображень (диск VM чи R2) і строк зберігання варіантів.
- Ліміти Figma API на тарифі власника.
- Чи знадобиться запасний хмарний шлях для зображень.
