# Обговорення: інфраструктура на домашньому Proxmox

- **Статус:** обговорення (рішень ще немає)
- **Створено:** 2026-11-05

У власника проєкту є домашній міні-сервер на Proxmox, де можна створювати
контейнери/VM під Adelie.

## Що це дає

1. **Спільне dev-середовище для двох ПК.** PostgreSQL і Redis на сервері →
   з обох ПК працюємо з тими самими даними (підключені акаунти, накопичені snapshots).
   Із локальним Docker Compose на кожному ПК дані розходились би.
2. **Ранній збір історії.** Worker на сервері може щодня синхронізувати Pinterest
   Gushka вже з етапу 2 — історія метрик накопичується, поки ми пишемо UI.
   Це цінно: історію до підключення API може не віддати (ТЗ 6.4).
3. **Можливий staging / перший production для Gushka** (етап 4) — без витрат на хостинг.

## Варіант організації (пропозиція)

- Одна VM (Debian/Ubuntu) з Docker → docker compose: postgres, redis,
  пізніше api + worker + web. VM надійніше для Docker, ніж LXC.
- Доступ з ПК — через Tailscale (або LAN, якщо обидва ПК вдома).
- `docker-compose.yml` у репо працює і локально, і на сервері — можна
  запускати все на ПК, якщо сервер недоступний.
- Бекапи: Proxmox backup VM + `pg_dump` за розкладом.

## Що треба врахувати

- **Публічний доступ і OAuth.** Для production-callback'ів платформ і для
  Gushka потрібен HTTPS-домен. Варіанти: Cloudflare Tunnel (без відкриття портів),
  reverse proxy з Let's Encrypt. Для dev OAuth, можливо, вистачить localhost — перевірити на етапі 0.
- **Надійність production вдома:** світло, інтернет, домашній IP. Для MVP з одним
  клієнтом прийнятно; для платних клієнтів — переглянути.
- **Безпека:** токени соцмереж зберігаються зашифровано; сервер не відкривати
  назовні напряму.

## Відкриті питання

1. Обидва ПК вдома в одній мережі, чи один поза домом? Чи є Tailscale/VPN?
2. Ресурси сервера (CPU/RAM/диск) — скільки можна виділити?
3. ~~Чи є домен?~~ Є: `uamade.xyz`. Чи DNS на Cloudflare?
4. Хто налаштовує VM: власник вручну, чи дати SSH-доступ до VM для автоматизації?
5. Використовуємо сервер лише для dev, чи одразу плануємо його як production для Gushka?
