# План: календар публікацій і огляд тижня

Рішення — [ADR-0028](../decisions/0028-content-calendar.md).

- [x] Модель даних: `calendar_item`, `weekly_review`, `project.dailyMinutes` (лише нові таблиці й поле).
- [x] API: записи (створення, зміна, перенесення, видалення), бюджет часу, автоматичне «опубліковано» за посиланням у
      синхронізованому дописі; огляд тижня (план і факт, результати посилань і дописів, підсумки за каналом і форматом,
      висновок, «виміряно»). Спільний підрахунок результатів посилань з Link Builder.
- [x] Інтерфейс: «Просування → Календар» — тиждень по днях і «Ідеї», перетягування, бюджет часу; вікно запису з
      посиланням (створити з каналом запису або вибрати) і дописом; вкладка «Огляд тижня».
- [ ] Перевірка власником на dev: запланувати тиждень Gushka, опублікувати пін/пост з посиланням, переглянути огляд.
- [x] Бриф проєкту (вкладка «Бриф») і «Запропонувати ідеї» — AI, журнал `ai_run`, ліміт $5/міс на проєкт
      ([ADR-0029](../decisions/0029-ai-brief-and-ideas.md)). Модель `gpt-6.1-terra`; один запит ≈ $0.005–0.02.
- [ ] Далі: стратегія (ціль, канали, ритм); висновок тижня від AI за цифрами огляду; підказки назв і тегів; місячний
      вигляд за потреби.
