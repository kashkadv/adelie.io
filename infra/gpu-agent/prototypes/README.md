# Прототипи вирізання (етап 0 майстерні публікацій)

Експериментальні скрипти, на яких перевірено конвеєр вирізання (див. [plans/pin-workshop.md](../../../docs/plans/pin-workshop.md)).
Це не продукт: агент (`infra/gpu-agent`) перепише їх під воркфлоу ComfyUI/чергу завдань. Шляхи вшиті під ПК власника
(`~/ComfyUI/input/gushka`, `~/ComfyUI/output/etap0`).

Порядок:

1. `sam_stage1.py "p2=a shaggy pillow."` — GroundingDINO за текстом знаходить рамку, SAM2 дає маску виробу (з трьох варіантів
   береться найбільший, що вміщується в рамку; кілька підказок через `|` — маски об'єднуються).
2. `sam_excl.py "p4=a handbag. a hand. a face."` — маски «чужого» поряд (сумка, рука, обличчя, волосся, стілець).
3. `sam_stage2.py 35 p2 p4` — SAM-маска лише вказує ділянку (розширену на 35 px), тонкі пасма знаходить BiRefNet на
   обрізку; від ділянки віднімається «чуже»; далі відновлення кольору краю й стиснення маски на 1 px.

Етапи 1–2 — у `~/ComfyUI/venv` (transformers 5, torch cu128, GPU); етап 3 — в окремому оточенні з `rembg[cpu]`
(BiRefNet через ONNX, `pymatting`).
