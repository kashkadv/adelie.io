# Прототипи вирізання (етап 0 майстерні публікацій)

Експериментальні скрипти, на яких перевірено конвеєр вирізання (див. [plans/pin-workshop.md](../../../docs/plans/pin-workshop.md)).
Це не продукт: агент (`infra/gpu-agent`) перепише їх під воркфлоу ComfyUI/чергу завдань. Шляхи вшиті під ПК власника
(`~/ComfyUI/input/gushka`, `~/ComfyUI/output/etap0`).

Порядок:

1. `sam_stage1.py "p2=a shaggy pillow."` — GroundingDINO за текстом знаходить рамку, SAM2 дає маску виробу (з трьох варіантів
   береться найбільший, що вміщується в рамку; кілька підказок через `|` — маски об'єднуються).
2. `sam_excl.py "p4=a handbag. a hand. a face."` — маски «чужого» поряд (сумка, рука, обличчя, волосся, стілець).
3. `sam_stage2.py 35 p2 p4` — SAM-маска лише вказує ділянку (розширену на 35 px), тонкі пасма знаходить BiRefNet на
   обрізку; від ділянки віднімається «чуже»; далі відновлення кольору краю й стиснення маски на 1 px.
4. `finalize.py p2 p5 p4` — прибирає відірвані шматки (площа ≥ 120 px, далі 12 px від основного тіла) і домальовує замкнуті
   отвори LaMa (`big-lama.pt`, TorchScript, на обрізку навколо отвору); модель — у `~/ComfyUI/models/lama/`.

Етапи 1–2 — у `~/ComfyUI/venv` (transformers 5, torch cu128, GPU); етап 3 — в окремому оточенні з `rembg[cpu]`
(BiRefNet через ONNX, `pymatting`).

## Повний конвеєр (актуальний)

`pipeline_full.py p2 p5 p4` — усе в одному проході на оригінальній роздільності й на GPU: ділянка SAM (+35 px) мінус «чуже» →
BiRefNet HR-matting (1536 px, fp16) на обрізку → відсів відірваних шматків → відновлення кольору краю → стиснення маски
1 px → LaMa для замкнутих отворів. Маски SAM беруться з файлів етапів 1–2. Оточення — `~/birefnet-test` (CUDA-PyTorch,
`numpy<2`, `pymatting`); ≈ 4–5 с на фото (2000×3000). `hr_alpha.py`, `hr_gpu.py`, `hr_compare.py` — перевірки HR-matting.

Режими вирізання (змінні оточення `pipeline_full.py`): `CORE=10` — «суцільний» (глибше 10 px від краю маска не бере з матингу,
а з замкнутої маски SAM: для в'язки/щільного текстилю); без `CORE` — «волосистий» (лише матинг: довгий ворс/хутро). `SMALL=…`
(заливка малих дірок) — експеримент, відкинуто (крапчастий вигляд).
